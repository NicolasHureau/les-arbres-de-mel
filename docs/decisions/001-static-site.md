# Décision

Utiliser un site statique Vue 3.

## Contexte

Le site est destiné à une artisane.

Le budget d'hébergement est très limité.

Les modifications sont peu fréquentes.

## Décision

Utiliser Vue 3 + fichiers JSON + Cloudflare Pages.

## Conséquences

+ Hébergement gratuit
+ Peu de maintenance
- Pas de backend dynamique
